# 首尔 SG 返点查询工具 · Seoul SG Rebate Inquiry Tool

一个面向移动端的单页应用（无后端、零依赖构建），用于快速查询和对比韩国首尔各大免税店/商场
「SG 模式」返点比例，替代难以在手机上浏览的静态长图。

**在线使用方式：** 直接用浏览器打开 `index.html`，或部署到任意静态托管
（GitHub Pages / Vercel / Netlify 等）。

## 功能

| 需求 | 实现 |
|---|---|
| 双分类导航 | 顶部 Tab 切换「综合/奢侈品/时尚」与「香化」两套数据 |
| 智能图片识别 (OCR) | 上传返点表截图，Tesseract.js（中/英文）在浏览器本地识别并解析为结构化行；导入前提供逐格可编辑的校对预览 |
| 实时搜索 | 顶部固定搜索栏，中文或英文品牌名即输即筛，匹配文字高亮 |
| 六店对比 | 新世界 / 新罗 / 现代 / 乐天明洞 / 乐天蚕室 / A'CHEER 六列并排，横向滑动 + 品牌列固定 |
| 视觉警示 | `0%` 红色警示、`无柜台` 灰色标记、本行最高返点绿色高亮；页首常驻免责声明 |
| 数据敏捷 | 数据存储在浏览器 localStorage；支持导出/导入 JSON、手动添加品牌、一键恢复示例数据 |
| 移动优化 | 响应式布局、粘性表头与品牌列、16px 输入框防 iOS 缩放、深色模式适配 |

## 数据说明

- 仓库内置的是**示例数据**，仅用于演示界面与交互；实际返点请通过 OCR 上传最新返点图或导入 JSON 更新。
- 数值语义：数字 = 返点百分比；`0` = 0% 警示；空/`-` = 无柜台；支持 `10-15` 这类区间字符串。
- 所有数据仅保存在使用者本机浏览器中，不会上传任何服务器。

## OCR 使用提示

1. 点击「数据管理 → 上传返点图 OCR 识别」，可多选图片。
2. 识别引擎（Tesseract.js v5，`eng + chi_sim`）首次使用时从 CDN 懒加载，需联网。
3. 解析规则：从每行末尾提取 3–6 个比例类 token（数字/`%`/`-`/`无柜台`/区间），其余部分作为品牌名并自动拆分中英文。
4. 识别结果先进入校对表格，可修改任意单元格或删除行，确认后按品牌名（中或英）合并覆盖导入。
