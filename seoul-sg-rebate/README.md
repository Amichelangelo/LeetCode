# 首尔 SG 返点查询工具 · Seoul SG Rebate Inquiry Tool

一个面向移动端的 PWA（无后端、零依赖构建），用于快速查询和对比韩国首尔各大免税店/商场
「SG 模式」返点比例，替代难以在手机上浏览的静态长图。

**在线使用：** 部署在 GitHub Pages（见仓库 Actions 的 Deploy 工作流输出地址），
手机浏览器打开后可「添加到主屏幕」，之后像 App 一样离线使用。
也可直接用浏览器打开 `index.html`，或部署到任意静态托管。

## 功能

| 需求 | 实现 |
|---|---|
| 双分类导航 | 顶部 Tab 切换「综合/奢侈品/时尚」与「香化」两套数据 |
| 智能图片识别 (OCR) | 上传返点表截图，Tesseract.js（中/英文）在浏览器本地识别并解析为结构化行；导入前提供逐格可编辑的校对预览 |
| 实时搜索 | 顶部固定搜索栏，中文或英文品牌名即输即筛，匹配文字高亮 |
| 六店对比 | 新世界 / 新罗 / 现代 / 乐天明洞 / 乐天蚕室 / 爱宝客(A'CHEER) 六列并排，横向滑动 + 品牌列固定 |
| 视觉警示 | `0%` 红色警示、`无柜台` 灰色标记、`详询` 琥珀色标记、本行最高返点绿色高亮；页首常驻免责声明；基础点与各店 0% 名单收纳在须知面板 |
| 数据敏捷 | 内置数据在 `data.js`（4.18 更新版返点表人工转录）；本地修改存 localStorage；支持导出/导入 JSON、手动添加、一键恢复 |
| 移动优化 | 响应式布局、粘性表头与品牌列、深色模式、PWA 离线缓存与主屏幕安装 |

## 数据说明

内置数据转录自商场发布的「首尔SG模式返点 4.18更新」及「【香化类】4.18更新」两张返点表图片。
单元格语义与原表一致：

- 数字 = 返点百分比；`0` = 0% 零返点（红色警示）
- `无` = 该店无柜台
- `-` = 未单列，**按顶部基础点结算**（基础点表见页内须知面板）
- `询` = 详询特殊团
- 其它字符串（如 `21%(包包)`、`18%(7折12%)`）原样显示

所有数据仅保存在使用者本机浏览器中，不会上传任何服务器。
**返点比例随时可能调整，购物当天请以店内实际政策为准。**

## 更新数据的两种方式

1. **页面内 OCR**：数据管理 → 上传最新返点图 → 校对 → 合并导入（存本机 localStorage）。
2. **改仓库数据**：编辑 `seoul-sg-rebate/data.js`（格式见文件头注释），推送后 GitHub Actions
   自动重新部署，所有用户刷新即得新数据（`data.js` 走 network-first 缓存策略）。
   改动数据结构时同步递增 `version` 字段，可让用户端自动放弃旧的本地缓存数据。

## 部署

`.github/workflows/deploy-pages.yml` 会在 `seoul-sg-rebate/` 有改动时把该目录发布到
GitHub Pages（首次运行自动开启 Pages，无需手动设置）。
